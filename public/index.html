As 3 tabelas de preço

Sempre que você calcular um preço, o sistema mostra 3 opções lado a lado. Você escolhe qual usar conforme o cliente e a situação:

  • 🎯 TETO (Tabela 1 — mais cara)
    Ponto de partida da negociação. Use em clientes que não comparam orçamento, primeira oferta, ou quando você é a escolha preferida.
  • ⭐ PADRÃO (Tabela 2 — moderada)
    Preço-alvo. Deve ser o default em 70% dos orçamentos. Competitivo mas com margem saudável.
  • ⚠️ PISO (Tabela 3 — mais barata)
    Limite. Use em negociações competitivas ou clientes estratégicos. Abaixo disso, só com autorização.
Hierarquia de descontos
  • ✅ Até o PISO: pode fechar direto, sem aprovação.
  • ⚠️ Até 5% abaixo do PISO: você pode oferecer, mas o sistema exige justificativa por escrito. Use só quando realmente necessário.
  • 🔴 Mais de 5% abaixo do PISO: bloqueado. Contate o gerente antes de prometer qualquer coisa ao cliente.
Fluxo recomendado
  1. Use a Calculadora para ver os 3 preços. Comece oferecendo o TETO.
  2. Se o cliente pedir melhor preço, use a aba Cálculo Reverso → Cliente ofereceu para checar se a contraproposta dele ainda faz sentido.
  3. Antes de fechar, simule o impacto da forma de pagamento na aba Pagamento.
  4. Salve a cotação no Histórico e atualize o status conforme ela evolui.
  5. Quando fechar, envie o orçamento oficial pelo WhatsApp.
